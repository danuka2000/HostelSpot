# HostelSpot Mobile - Boutique Student Accommodation Platform

Mobile client application for **HostelSpot** built with React Native, Expo, NativeWind, and Tailwind CSS.

## Visual Identity & Design System
- **Primary**: Deep Forest Green (`#122C23`)
- **Secondary**: Muted Sage (`#E4ECE7`)
- **Accent**: Warm Clay (`#D9633B`)
- **Background**: Soft Cream (`#FAF8F5`)
- **Typography & Components**: Editorial design, Lucide icons, ticket-style vouchers, custom bottom tab navigation.

## Features
- JWT Auth session persistence with `AsyncStorage`
- Student & Admin role-based navigation and views
- Editorial Home discovery screen with featured horizontal carousel
- Explore screen with room type & status filter chips
- Room Details with edge-to-edge cover imagery & real-time occupancy
- Step-oriented booking flow & digital reservation vouchers
- Property Admin dashboard, inventory CMS, and application review queue

## Setup & Running
```bash
npm install
npm start
```
Press `w` for web, `a` for Android Emulator, or `i` for iOS Simulator.
